# GSI prefectural high points

- Source: 国土地理院「都道府県の最高地点」, https://www.gsi.go.jp/KOKUJYOHO/MOUNTAIN/todofuken.pdf
- Edition: 令和7年4月1日 (2025-04-01). Linked from the 日本の主な山岳標高 page.
- Licence: GSI content terms of use (compatible with CC BY 4.0). Attribution:
  出典：国土地理院「都道府県の最高地点」を加工して作成
- `todofuken.json`: one row per prefecture in table order. Names, readings and heights come
  from the table; coordinates from each row's 地理院地図 link. `jam lists fetch` refreshes the
  coordinates from the PDF and checks there are still 47 rows.

Four rows aren't named summits: 秋田県 (鳥海山東側の山腹), 福井県 (三ノ峰南側の頂),
大阪府 (金剛山南東の頂) and 福岡県 (釈迦岳南西の頂).
